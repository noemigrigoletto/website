# Project documentation

This directory is the durable project memory for the website.

## Contents

- [`decisions.md`](decisions.md) — product, content, design, and architecture decisions that should survive individual tasks.
- [`project-state.md`](project-state.md) — what is implemented, what remains incomplete, and where important content lives.
- [`state-of-the-art.md`](state-of-the-art.md) — verified framework versions, compatibility constraints, and the current technical approach.
- [`workflow.md`](workflow.md) — commands and checks for local work.

Update these documents when a change makes their content inaccurate. Avoid duplicating implementation details that are clearer in code.
